# Data

## PWC Gemona 2026

| File | Content | Source |
| --- | --- | --- |
| `gemona-2026/waypoints.wpt` | Competition waypoints (CompeGPS format) | PWCA |
| `gemona-2026/task2-igc.zip` | IGC tracks, task 2, 27 July 2026 | PWCA |
| `gemona-2026/task3-igc.zip` | IGC tracks, task 3, 28 July 2026 | PWCA |
| `gemona-2026/official/task2.csv` | Official results: rank, pilot, leading points, total | [scoring.pwca.org/gemona-2026/task2.html](https://scoring.pwca.org/gemona-2026/task2.html) |
| `gemona-2026/official/task3.csv` | Official results: rank, pilot, leading points, total | [scoring.pwca.org/gemona-2026/task3.html](https://scoring.pwca.org/gemona-2026/task3.html) |

The tracks and results are published by the Paragliding World Cup Association (PWCA). They are copied here for research on scoring only. The official CSV files list the pilots who reached ESS.

## Removing a track

A pilot who does not want their track or name in this repository can ask for it to be removed:

- open an issue titled "Track removal" with the competition, the task and the pilot's name, or
- contact the repository owner through GitHub.

The track will be removed from the data and from the replays. Note that it stays in the Git history unless the history is rewritten, which will be done on request.
